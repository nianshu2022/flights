# flights

甘肃 9 个机场航班数据归档。

## 目录结构

- 第一层按年份：`2026/`
- 第二层按月份：`2026/11/`
- 文件按日期命名：`20261101.json`、`20261102.json`、……、`20261130.json`

## 每个 JSON 文件的内容

当天甘肃 9 个机场（兰州中川、敦煌莫高、嘉峪关酒泉、天水麦积山、庆阳、金昌金川、张掖甘州、陇南成县、甘南夏河）的出港与进港航班：
航班号、起降机场、计划起降时间、实际起降时间（已执行航班）、是否取消、机型、代码共享。

## 数据来源与口径

FlightAware（经 Muse 托管服务调用）：计划时刻表与历史/当日运行表合并，代码共享已去重，只保留实际执飞航班。
2026-11-01 至 11-20 为已执行/当日数据，11-21 至 11-30 为计划时刻表，临近当天可能调整。
完整性为尽力口径：支线机场基本齐全，兰州中川可能差几班；临时加班、包机和部分货运航班不含。
